A small model, an inspectable pathway.

This project explores how a locally adapted language model can connect patient findings to a structured diagnostic knowledge graph.

  1. Read the caseD4 selects a disease category from the clinical record.
  2. Find the evidenceThe model selects passages. The pipeline preserves their original wording.
  3. Follow the criteriaDiagnostic milestones are chosen from the category’s supplied knowledge graph.
  4. Explain and exploreA separate teaching layer explains the saved decisions. Graphviz lays out the evidence connections.

What still goes wrong?

The model can select the wrong category, rely on a single nonspecific finding, or misread severity and timing. D4’s concise answers need scrutiny; a complete graph is not proof of a correct diagnosis.
